Informasi Status 'Perlu Perbaikan'?

Bila status tiket Anda bertuliskan Perlu Perbaikan, artinya dokumen foto KTP/KK buram atau NIK tidak sinkron di Dukcapil. Anda memiliki waktu 3x24 jam untuk memperbarui berkas tanpa membuat permohonan baru.
